# 授权离线应用配置来源

支持 REGF 1.3/1.5 主蜂巢，不挂载、不执行、不回放事务日志。文件头 regf，序列号 primary/secondary、root offset、hive bins size 及508字节的 XOR32 校验遵守 REGF 定义。hbin cell 按8字节对齐，负长度为已分配，正长度为空闲；所有 cell 引用相对4096起始的 hive bin 区域，必须落在已分配单元内且不跨单元读取。

支持 nk、vk，子键索引 li/lf/lh/ri，值列表和 db 分段大值；忽略 sk 内容但保留引用。键名 flags 0x20、值名 flags 0x1 表示压缩单字节名称，否则 UTF-16LE，不按本机区域设置猜测。值类型支持 NONE、SZ、EXPAND_SZ、BINARY、DWORD、DWORD_BIG_ENDIAN、MULTI_SZ、QWORD；值长度高位表示数据在 offset 字段内联，长度0不当成整数0。环境字符串不展开，MULTI_SZ 保留顺序，无法解释的原字节仍可定位。

只接收根可达且结构可靠的配置，不扫描空闲残留恢复记录；序列不一致时不声称文件是已同步快照。每条键值输出 keyPath、valueName、type、value、原始单元偏移和有效性。缺索引、循环及越界使受影响范围未决，不能把未决范围当作空键。

## 接收实现的边界保证

- 所有单元引用相对 4096 起始的 hive bin 区域，先建立 hbin/单元边界索引，再沿 nk 声明的 li/lf/lh/ri 子键索引与值列表访问；引用必须落在 8 字节对齐的已分配单元内，且读取不得跨出该单元。lf/lh 条目的 4 字节名称哈希与 nk 偏移分离，lh 偏移高位掩码后使用；ri 递归展开并对重复单元检测循环。
- 值列表单元无文本签名，数据区为 nk 声明数量的连续 vk 引用；数量以 nk 声明为准，不把首个引用的低位误读为内嵌计数。db 分段大值经段列表与段描述符按序拼接，任一段不可达即整体标记未决。
- 内联值（vk 长度高位标记，数据位于 offset 字段的 4 字节内）、外置值与 db 大值形成同构记录，dataLocation 区分 inline/external/big-data/empty 并保留来源单元偏移。
- 名称按 flags 选择 latin1（压缩单字节）或 UTF-16LE，不按本机区域设置猜测；REG_EXPAND_SZ 仅保留表达式（expanded 恒为 false），MULTI_SZ 保序，长度 0 视为空数据而非整数 0，无法解释的原字节以 hex 保留并标记 valid=false。
- 序列号主/次不一致产生 SEQUENCE_MISMATCH 缺口且不声称已同步；头部 XOR32 校验失败产生 CHECKSUM_MISMATCH；越界、未对齐、指向空闲单元、坏签名各自形成可定位 issue。解析器不在坏偏移附近搜索相似标记，不读取空闲单元内容，不恢复已删除记录，也不做密码或凭据提取（coverage 中 freeCellsScanned、deletedRecovered、environmentExpanded、credentialExtraction 恒为 false）。

本机来源 GET /manifest 给出 entry 与资源清单；GET /files/资源名 支持 Range 和 If-Match，GET /trace 提供实际访问记录。数据均为合成配置，不含账号密码。格式参考：https://github.com/libyal/libregf/blob/main/documentation/Windows%20NT%20Registry%20File%20(REGF)%20format.asciidoc。
