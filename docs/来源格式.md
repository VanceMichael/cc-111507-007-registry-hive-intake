# 车端售后日志来源格式

支持 DLT 存储头 DLT\x01、标准头与扩展头，HTYP 决定字节序及 ECU/session/timestamp 是否出现；storage 时间与设备时间分列。verbose 参数限带类型信息的 signed/unsigned 8/16/32、float32、UTF-8 string；non-verbose 起始 uint32 是 messageId，后续参数由 dictionaries 的 ECU/app/context/build 组合限定。manifest 提供 build 与 bootId；计数 uint8 回绕是连续，不代表时钟回绕。缺字典记录保留 raw，解释条目带 dictionaryDigest。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://github.com/COVESA/dlt-daemon。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
